# Mutual Fund Analytics

## Project Overview
This project analyzes mutual fund performance, investor behavior, and risk metrics using Python, SQL, and Power BI.

## Features
- Data Cleaning
- Exploratory Data Analysis
- Performance Analytics
- Risk Metrics (VaR, CVaR, Sharpe Ratio)
- Investor Analytics
- Fund Recommendation System
- Interactive Power BI Dashboard

## Technologies Used
- Python
- Pandas
- NumPy
- SQLite
- Power BI
- Git & GitHub

## Project Structure
data/
notebooks/
reports/
scripts/
dashboard/

## How to Run
1. Clone repository
2. Install requirements
3. Run notebooks in order
4. Open Power BI dashboard
